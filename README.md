# EZeats 🍴

Welcome to **EZeats**, your one-stop app for discovering, ordering, and tracking meals from your favorite restaurants. Designed with a user-friendly interface and powered by modern technologies, EZeats ensures a seamless dining experience.

---

## 🌟 Features
- **Discover Restaurants**: Browse nearby restaurants with detailed menus and reviews.
- **Order with Ease**: Place pickup or delivery orders in just a few clicks.
- **Tracking Order**: Track your delivery or pickup progress.
- **Personalized Experience**: Save favorite restaurants, reorder meals, and enjoy tailored recommendations.

---

## 🚀 Technologies Used
EZeats leverages modern tools and frameworks for a robust and scalable solution:

### **Frontend**
- **XML Layouts**: For creating structured and visually appealing user interfaces.
- **Navigation Component**: To handle navigation between screens in an intuitive and consistent manner.
- **Coil**: For efficient image loading and caching.

### **Backend**
- **Firebase Cloud Messaging (FCM)**: For push notifications and real-time updates.
- **Parse**: To manage backend services like user authentication, order management, and data storage.
- **Node.js**: For building a scalable, event-driven backend server.

### **Dependency Injection**
- **Hilt**: For simplified dependency injection, ensuring a clean architecture.

### **State Management**
- **ViewModel**: Manage UI-related data lifecycle-aware.
- **Coroutines & Flow**: For asynchronous operations and reactive programming.

### **Data Handling**
- **Base64**: For encoding and decoding image data before sending it to the backend.
- **DataStore**: For secure and efficient storage of user preferences.

### **Others**
- **Mixpanel**: For user behavior tracking and analytics.
- **ZXing Library**: For QR code scanning.

---

## 🛠️ App Flow

1. **Splash Screen**  
   Users are greeted with an engaging splash screen showcasing the app logo.

2. **Sign In/Sign Up**  
   Users can sign in or sign up using their phone numbers.

3. **Onboarding**  
   New users go through a brief onboarding process to learn about the app's key features.

4. **Home Screen**  
   Explore nearby restaurants and filter by cuisine, ratings, or distance.

5. **Restaurant Details**  
   View detailed menus, reviews, and available offers.

6. **Loyalty Points**  
   Use EZpoints to redeem offers, regardless of the restaurant.

7. **Order Tracking**  
   - **Pickup**: See progress through 3 steps: Order Received, In Preparation, Ready for Pickup.
   - **Delivery**: Track the progress in 4 steps: Order Received, In Preparation, Out for Delivery, Delivered.

8. **Profile Management**  
   Manage personal details, address book, and order history.
